# ICDFA-GRC102 – Information Security Governance

This repository contains my practical coursework and evidence for the **International Cybersecurity and Digital Forensics Academy (ICDFA) GRC102 – Information Security Governance** course.

The repository is organised by week, with each folder containing the relevant practical work, supporting evidence, and documentation.

## Course

**GRC102 – Information Security Governance**

**Institution:** International Cybersecurity and Digital Forensics Academy (ICDFA)

## Practical Work

### Week 1 – Information Security Governance in Action

The Week 1 practical is based on the **GlobalHealth Connect (GHC) executive governance simulation**.

Key areas covered include:

- Governance Blueprint
- Information Security Charter
- Board Reporting
- Security Steering Committee
- Governance Maturity
- Accountability and business alignment
- Risk management and board oversight

[View Week 1](./Week%201/)

### Week 2 – Developing Security Policies and Procedures

The Week 2 practical focuses on developing information security policies and procedures and understanding how they support effective security governance.

Key areas covered include:

- Information security policy development
- Security procedures
- Policy implementation
- Roles and responsibilities
- Compliance and accountability
- Policy review and continuous improvement

[View Week 2](./Week%202/)
